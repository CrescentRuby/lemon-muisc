# 柠檬音乐 v1.2.17.4

## 更新内容

- **切换音源**：试听 / 下载按「当前音源穷尽各平台 → 其他已激活音源 → 降质」顺序换源，减少无效重试、更快拿到可播可下地址
- **标签整理**：修复整理标签写回乱码（重复 ID3 帧导致）
- **网络 / 播放**：完善换源与跨平台匹配节奏；试听区显示平台与音质；关闭「本地转码」时直出失败并提示跳下一曲，开启时仍走流畅 AAC
- **全屏播放**：封面与歌词整体居中，加大左右间距
- **播放栏 / 全屏**：平台·音质角标与歌名并排时不再把歌名挤换行；长歌名省略号截断

## 安装 / 更新

- ARM：`lemon-music-1.2.17.4-arm.fpk`
