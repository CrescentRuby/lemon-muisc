# 柠檬音乐 v1.2.17.14

## 更新内容

- **投屏**：连播改由服务器维护队列，关掉手机或电脑界面后音箱仍会自动下一曲
- **下载**：手机端音质选择改为从左侧弹出，不再叠在「更多」菜单里
- **账户**：退出登录确认在手机上改为底部弹层
- **音源**：脚本声明的 qs / bili / ytb / xm 可在设置里开关（内置搜索仍为酷我 / 酷狗 / QQ / 网易云 / 咪咕）
- **设置**：音源平台列表改为锚定下拉，手机端尺寸缩小，不再盖住音源卡片

## 安装 / 更新

- x86：`lemon-music-1.2.17.14-x86.fpk`
- ARM：`lemon-music-1.2.17.14-arm.fpk`
