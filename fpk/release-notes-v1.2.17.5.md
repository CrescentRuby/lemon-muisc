# 柠檬音乐 v1.2.17.5

## 更新内容

- **播放弱网**：超时/中断时先换平台与音源重试，再跳下一曲；可弹窗开启「本地转码」
- **本地转码**：局域网访问时本地曲目直出原文件，外网仍按开关转码（APE/DSD 除外）
- **发现页**：服务端磁盘预缓存与后台预热，减轻刷新卡顿
- **本机试听缓存**：成功试听可写入浏览器本地缓存（设置可开关与容量）
- **下载**：分组不再建「未知专辑」空文件夹；导航显示进行中下载数
- **歌单**：支持管理多选、清理空歌单 / 导入歌单
- **设置 / 手机**：平台开关改为卡片内下拉；设置页打开回到页头；确认弹窗更紧凑

## 安装 / 更新

- x86：`lemon-music-1.2.17.5-x86.fpk`
- ARM：`lemon-music-1.2.17.5-arm.fpk`
